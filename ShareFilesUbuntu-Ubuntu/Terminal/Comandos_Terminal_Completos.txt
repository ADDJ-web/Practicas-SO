[PASO 2: INSTALACIÓN Y CONFIGURACIÓN DEL SERVIDOR SAMBA]
------------------------------------------------------------------------------
israel@israel-BOM-WXX9:~$ sudo apt update && sudo apt install -y samba
israel@israel-BOM-WXX9:~$ mkdir -p ~/Escritorio/IsrAMBA/1
israel@israel-BOM-WXX9:~$ chmod -R 777 ~/Escritorio/IsrAMBA

# Agregar bloque de compartición al archivo /etc/samba/smb.conf:
# [IsrAMBA]
#    comment = Carpeta Compartida Ubuntu a Ubuntu
#    path = /home/israel/Escritorio/IsrAMBA
#    browseable = yes
#    read only = no
#    create mask = 0777
#    directory mask = 0777
#    valid users = israel

israel@israel-BOM-WXX9:~$ sudo smbpasswd -a israel

israel@israel-BOM-WXX9:~$ sudo systemctl restart smbd

[PASO 3: CONEXIÓN DESDE NAUTILUS (EXPLORADOR DE UBUNTU)]
------------------------------------------------------------------------------
# 1. En el equipo cliente, abrir el explorador de archivos Nautilus.
# 2. Hacer clic en "Otras ubicaciones" (o "Red").
# 3. En "Conectar al servidor" escribir la URI de red:
#    smb://192.168.1.2/
# 4. Nautilus lista los recursos compartidos:
#    - IsrAMBA (recurso compartido de la práctica)
#    - print$ (servicio de impresión por defecto de Samba)
# 5. Al hacer doble clic en 'IsrAMBA', solicita credenciales de red:
#    Usuario: israel
#    Dominio: WORKGROUP
#    Contraseña: [contraseña de smbpasswd]
# 6. Se abre el recurso mostrando la carpeta '1' y los elementos compartidos.
# 7. Ambos equipos pueden crear, leer, modificar y transferir archivos de forma instantánea.
