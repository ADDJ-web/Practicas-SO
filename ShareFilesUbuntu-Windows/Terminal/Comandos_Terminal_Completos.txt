[PASO 3: CONEXIÓN UBUNTU A UBUNTU EN EL EXPLORADOR (NAUTILUS)]
------------------------------------------------------------------------------
# En la segunda máquina Ubuntu:
# 1. Abrir la aplicación "Archivos" (Nautilus).
# 2. Hacer clic en "Otras ubicaciones" o barra de búsqueda en "Red".
# 3. En "Conectar al servidor" escribir:
#    smb://192.168.1.2/isramba
# 4. Introducir las credenciales creadas:
#    Usuario: israel
#    Contraseña: [la definida en smbpasswd]
# 5. Se accede al recurso compartido mostrando la carpeta '1' (como se documenta en la imagen 01).

[PASO 4: CONEXIÓN UBUNTU A WINDOWS VÍA ETHERNET]
------------------------------------------------------------------------------
# En la máquina con Windows 10/11:
# 1. Conectar cable Ethernet y asegurar que la IP esté en el segmento 192.168.1.x (255.255.255.0).
# 2. Presionar el atajo de teclado: Windows + R
# 3. Escribir: \\192.168.1.2\
# 4. Windows muestra una ventana de autenticación de red:
#    Usuario: israel
#    Contraseña: [la definida en smbpasswd]
# 5. Se abre el Explorador de Archivos de Windows mostrando el recurso 'isramba' y la carpeta '1'.
# 6. Se pueden transferir archivos bidireccionalmente arrastrando y soltando.
